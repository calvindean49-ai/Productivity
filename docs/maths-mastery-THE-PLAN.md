## 1. The alignment — where the two goals are the same work

You asked for a plan that serves the tests *and* the mathematician goal. The earlier answer split them by
day, which is a truce, not an alignment. Here is the real structure:

**There is a large overlapping core that serves both goals at once, and two thin wings that serve only
one each.** The core is about 70% of the time. Build the plan on the core and the conflict mostly
disappears.

| | Serves the tests | Serves the mathematician |
|---|---|---|
| **THE CORE — default work** | | |
| Proof written to marking standard, then revised | FM and Maths lose marks on incomplete arguments | Rigour and communication are the attributes everything else routes through |
| **TMUA Paper 2: logic and proof** | Half the TMUA | **Implication, contrapositive, quantifiers, necessary vs sufficient, finding the broken step — this is the opening chapter of every undergraduate analysis course.** Not exam technique. Foundational content. |
| Interleaved problem sets, method never stated | Exams never tell you which method | Conditional knowledge — where your logged failures cluster, and where experts separate |
| Error analysis: locating the failing step | Explicit TMUA Paper 2 syllabus item | Studying broken arguments beats straight problem-solving on delayed tests |
| Look-back, 10 min (second proof? weakest hypothesis? generalise?) | Deepens schema, which raises exam ceiling | Generalisation and taste live here |
| **WING A — tests only** | | |
| Timed papers, triage and checking protocol | Necessary | Nothing |
| **WING B — mathematician only** | | |
| Olympiad problems, rigorous reading | Nothing (unless BMO1) | Everything |

**The claim this plan rests on:** if you only ever did the core, you would be training for the tests and
becoming a mathematician simultaneously, and you would be doing the best-evidenced things in the field
while you did it. The wings are what you add when there's room.

## 2. The weekly engine — three tiers, not a timetable

The old plan assumed 15–17 hours a week. That number had nothing under it, and you've said time is
scarce. **A fixed schedule breaks on the first bad week and then stays broken.** Tiers don't.

### Tier 1 — the floor. ~5 h. This happens in every week, including bad ones.

| | Time |
|---|---|
| **Daily 20 min retrieval**, alternating: maths (definitions, validity conditions, standard forms) and Physics/Chemistry | ~2h20 |
| **One interleaved problem set, 90 min**, marked against official solutions, no two consecutive problems on the same method | 1h30 |
| **One proof written to marking standard**, then revised after critique | 1h |

Tier 1 alone trains fluency, method selection, rigour and communication, and covers all four A-levels.
A month of Tier 1 only is not a failed month.

### Tier 2 — the normal week. ~+4 h → about 9 h.

| | Time |
|---|---|
| **Second interleaved set, 90 min**, aimed at the current phase target | 1h30 |
| **TMUA Paper 2 block, 60 min** — the overlap spine, runs all year | 1h |
| **Struggle floor: 45 min cold on one unfamiliar problem, then the full model solution, then the look-back** | 1h15 |

### Tier 3 — a good week. ~+3.5 h → about 12 h.

| | Time |
|---|---|
| Olympiad topic session | 1h30 |
| Reading block — Zeitz now, a rigorous text in the summer | 1h |
| Second TMUA block, or a full timed paper in Phase 3 | 1h |

**Twelve real hours beats sixteen planned ones.** Record which tier you actually hit each week. That one
number is worth more than the whole eight-field log.

**Non-negotiables, unchanged:** demanding work stops at 22:00, bed at 22:30. Three nights past it in one
week means the plan is over budget — drop a tier, don't drop sleep.

- Tier 3 becomes A-level past papers, not olympiad.

**Phase E — Exams. 10 May → 22 Jun.** National window is 10 May to 22 June, contingency 23 June; your OCR
papers may finish earlier. STEP 2 mid-to-late June if it's live. Nothing to plan.

**Phase F — The free summer. 23 Jun → ~19 Aug.**
Eight to ten unconstrained weeks — more usable maths time than October through December combined, and
the only place the mathematician goal runs without competition. Pre-committed now, detail decided in May:
one rigorous analysis text with the exercises, one algebra text, the parked problems from §3 finally
closed out, one written mathematical object of your own, and real rest. **Not coursework, not Aether.**
Aether can have August.

## 5. The destination — what August 2027 should look like

Eleven months does not produce expertise in the usual sense; expert pattern libraries run to 10⁴–10⁵
domain-specific chunks over something like a decade. The reachable destination is **undergraduate-ready:
the first year of a good maths degree is a continuation rather than a shock.** Six claims, each checkable,
so the goal isn't a feeling:

| Claim | Test |
|---|---|
| Proof is a native mode, not a translation | Write a correct, complete proof of an unfamiliar result without reaching for a template |
| Rigour is internalised | You spot your own hidden assumptions before anyone else does — the §3 cyclic-quadrilateral failure does not recur |
| Abstraction doesn't repel you | Follow a definition–theorem–proof text at roughly a page every twenty minutes |
| Real first contact with undergraduate mathematics | One rigorous analysis text and one algebra text worked through, with the exercises |
| Tolerance for not knowing | Time-to-first-abandonment on an unfamiliar problem measured in hours, not minutes |
| Taste has started | The conjecture book holds entries you generated, not prompts you were given |

Not on that list: a BMO medal, a TMUA 9, an olympiad ranking. Those are instruments. Phase F is where
most of this gets built.

## 6. Two rules for when it goes wrong

Decided now, in the cold, because these are the two failures most likely to happen and least likely to be
handled well in the moment.

**If the log dies.** Two consecutive weeks with no entries means it is not restarted — it is **cut to one
field, `next retest`, and nothing else.** A one-field log that runs beats an eight-field log that doesn't.
This is the predicted failure, not a hypothetical: systems of that weight have a poor survival rate.

**Results day, ~19 August 2027.** Written now because it won't be writable then. A missed grade is
unlikely to be Maths. If it's **Chemistry or Physics**, you had a grade of buffer, so the offer probably
survives — check the exact conditions before panicking. If it's **Further Maths**, both routes are hit and
adjustment is the path. **Have the adjustment list drafted in July** (Gate 9) — thirty minutes then, worth
an enormous amount on the day.
